A small UI kit inspired by Coca-Cola

A colour palette, type scale, and eight reusable components built around Coca-Cola's brand identity — then applied consistently across two sample app screens.

This is an original UI kit inspired by Coca-Cola's public brand identity (its red, and its energetic, friendly tone) for a design-systems coursework exercise. It doesn't reproduce Coca-Cola's official logo, custom typeface, or any proprietary assets — the wordmark below is set in a standard typeface, not the brand's trademarked script.
